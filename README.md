### 🟣 About Me

I'm a first-year B.Tech CSE (AI) student at **UEM Kolkata**, currently building the foundation of a software engineering skillset — starting with **C and Python**, and branching into **AI/ML and computer vision** through hands-on projects rather than coursework alone.

I like turning small, concrete ideas into working prototypes: a gesture-controlled slide deck, a health-monitoring concept, browser-based tools. I'm early in the journey, and I'm intentionally building in public so the growth is visible over time.

Outside of code, I draw — mostly creative and portrait-style work. I think of drawing and programming as two versions of the same instinct: building something out of nothing.

**🎯 Currently open to:**
- Beginner-friendly open-source contributions
- Collaborating on small AI/CV or Python projects
- Learning from people further along the path than me

### 🟣 Featured Projects

<details>
<summary><b>🖐️ Hand Gesture Presentation Controller</b></summary>
<br/>

A webcam-based tool that lets you control slide presentations using hand gestures instead of a keyboard — built as a computer vision prototype, later reframed as an assistive-tech concept for motor-impaired users for a college ideathon pitch.

| Aspect | Detail |
|---|---|
| Stack | Python, OpenCV, MediaPipe |
| Status | Working prototype |
| Interaction | 4 fingers → next slide · 3 fingers → previous slide |
| Angle | Accessibility / assistive technology |
| Repository | [github.com/supriyakarmakarr](https://github.com/supriyakarmakarr) |

Real-time hand landmark detection drives slide navigation without any physical input device — a first hands-on project in applied computer vision.

</details>
